# IT Academy Management System

## Pages
- Home, Project Overview, Login, Dashboard
- Students (add/search records), Courses, Fee Tracking, Progress & Certificates
- Requirements (searchable) and Project Models

## Notes
- Each page has its own URL and navigation, rather than one long page.
- Login is a front-end demonstration only; it is not secure authentication.
- Student additions are saved in your current browser using localStorage.
- Fees, statistics and course catalogue contain illustrative sample data.
- No server or installation is needed.
